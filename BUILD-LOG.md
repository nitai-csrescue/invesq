# Build Log

Append-only build self-report log. Every completed (or partially completed / blocked)
build task appends **one** entry at the **end** of this file, using the exact template
below. `GET /api/build-status` (public, no auth) parses the **last** entry in this file
and returns it as JSON.

Do not edit or delete past entries — this file is a historical record.

## Entry template

```
## <Task name>
- Date: <YYYY-MM-DD HH:MM UTC>
- Status: complete | partial | blocked
- Files changed: <short list or summary>
- Validation: <typecheck + startup validation result>
- Republish needed: yes | no
- QA notes:
  - <note>
  - <note>
```

Separate entries with a `---` line.
